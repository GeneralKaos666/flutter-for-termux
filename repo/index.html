flutter-for-termux apt repository

This is the apt repository for flutter on Termux. The signing key is key.gpg; the snippet below installs gnupg, creates the apt keyrings directory, stores the key as $PREFIX/etc/apt/keyrings/flutter.gpg and adds the repository to $PREFIX/etc/apt/sources.list.d/flutter.list.

Quick start

pkg install -y gnupg
mkdir -p "$PREFIX/etc/apt/keyrings"
curl -fsSL https://GeneralKaos666.github.io/flutter-for-termux/key.gpg \
  | gpg --dearmor > "$PREFIX/etc/apt/keyrings/flutter.gpg"
echo "deb [signed-by=$PREFIX/etc/apt/keyrings/flutter.gpg] https://GeneralKaos666.github.io/flutter-for-termux termux main" \
  > "$PREFIX/etc/apt/sources.list.d/flutter.list"
pkg update && pkg install flutter
flutter doctor

Full instructions live in the README quick start. Never run flutter upgrade; use apt upgrade flutter instead.
